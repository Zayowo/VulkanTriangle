## Vulkan Triangle
**Projet en C++ avec l'API graphique Vulkan (1.4.357)** et des librairies supplémentaires (GLFW, GLM et STB). Il a pour but d'apprendre le fonctionnement de Vulkan et d'expérimenter avec celui-ci.

## Comment l'utiliser?
Ce projet n'a pas pour but d'avoir une *Release*. Mais, vous pouvez cloner le dépôt et regardez par vous même le code et l'éxécuter. Vous avez besoin de Vulkan 1.4.357 installé. *Et aussi voir un cube texturé qui tourne sur lui-même! :D*

## Qu'est-ce ce projet est capable de faire?
Le projet est capable d'afficher un cube texturé qui tourne avec un fond coloré. La fenêtre de l'application peut être redimensionner, réduite ou en pleine écran sans problème. La pipeline graphique fonctionne correctement. Création de la *window GLFW*, création de l'*instance Vulkan*, en passant par la *swap chain*, la *graphics pipeline* et les différents *buffers* afin de permettre une *communication optimale entre le CPU et le GPU*. Et également la capacité d'afficher un *objet texturé* avec de la *profondeur*.

## Peut-il être améliorer?
**Complétement.** L'affichage de plusieurs objets avec des différents modèles serait la plus grande amélioration. Le contrôle de la caméra peut également être implémenter grâce à GLFW qui fournit une API pour les inputs.
