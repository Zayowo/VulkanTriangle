## Vulkan Triangle
**Projet en C++ avec l'API graphique Vulkan** et des librairies supplémentaires (GLFW, GLM et STB). Il a pour but d'apprendre le fonctionnement de Vulkan et d'expérimenter avec celui-ci.

## Comment l'utiliser?
Ce projet n'a pas pour but d'avoir une *Release*. Mais, vous pouvez cloner le dépôt et regardez par vous même le code et l'éxécuter. *Et aussi voir un cube texturé qui tourne sur lui-même! :D*
